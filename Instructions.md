# Build Instructions

Deployed to **GitHub Pages**. GitHub Pages fully supports **client-side JavaScript**
(it only lacks a server), so JS is allowed and used for the interactive experience.

Build this as a next-level, **Gen-Z "aura" portfolio** — memorable and cinematic, in the
spirit of the reference site: https://www.msport-raptor.com/

- **Persistent dark/light theme** that remembers the choice across every page and follows
  the system preference (no flash on load).
- **Living neural-network background** (animated canvas) as the signature motif — the AI
  equivalent of the reference site's car intro.
- **Next-level scroll experience** — scroll-driven reveals, parallax/depth, and section
  transitions that unfold as you move down the page.
- **Micro-interactions** — subtle hover/click sounds and a calm ambient audio loop, both
  **off by default** behind a visible mute toggle (browsers block autoplay).
- Freedom to break away from the default page structure and background.

- images : https://pixabay.com/photos/

Constraints & principles:

- Keep the file and folder structure **minimalistic**.
- Everything must run on static hosting (no backend).
- Respect `prefers-reduced-motion`; keep it fast and accessible; sound stays opt-in.
