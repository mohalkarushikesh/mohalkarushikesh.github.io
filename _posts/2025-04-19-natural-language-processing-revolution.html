Modern NLP systems are compositions of tokenization, representation learning, retrieval, generation, and policy. The language model is important, but a reliable application also needs evidence selection, structured outputs, evaluation, and controls for hallucination and data leakage.

Transformer computation

Causal self-attention computes a query-key compatibility matrix while masking future tokens. The output combines value vectors according to normalized scores:

Attention(Q,K,V) = softmax((Q K^T) / sqrt(d_k) + mask) V

Rotary position embeddings encode relative rotation into query and key dimensions. Grouped-query or multi-query attention shares key/value heads to reduce the KV cache during decoding. These choices affect context capacity, memory bandwidth, and quality rather than existing independently of serving constraints.

Retrieval-augmented generation

RAG moves changing knowledge out of the model weights. A typical pipeline chunks and normalizes documents, creates dense and lexical representations, retrieves candidates, reranks them, and supplies the final evidence to the generator with source identifiers.

query -> hybrid retrieve -> rerank -> context budget -> generate -> cite

Evaluate retrieval separately from generation using recall@k, precision@k, and answerable-context rate. Evaluate generation for groundedness, citation correctness, completeness, and refusal when evidence is insufficient. Chunk size, overlap, metadata filters, and query rewriting can matter more than changing the language model.

Adaptation methods

Full fine-tuning updates every parameter and requires substantial optimizer memory. LoRA learns low-rank updates:

W' = W + (alpha / r) B A

Adapters make domain specialization cheaper and reversible, but the base model can still retain unsafe or outdated behavior. Instruction data should be checked for contradictions, personally identifiable information, and evaluation contamination.

Quantization reduces weight and activation precision. Weight-only quantization often provides a useful memory reduction with limited quality loss, but validate long-context retrieval, structured output, multilingual behavior, and tool calls rather than relying on perplexity alone.

Evaluation

Build an evaluation set from real task types and failure modes. Include adversarial prompts, unanswerable questions, conflicting documents, long contexts, and schema violations. Track exact match where appropriate, semantic correctness, citation support, refusal precision, latency, token cost, and regression by model version.

Human preference is useful but noisy. Pairwise review needs clear rubrics, blinded model identity, inter-rater analysis, and examples of unacceptable behavior. Automated judges should be calibrated against human labels and never be the only release gate for high-impact tasks.

Efficient serving

Continuous batching improves accelerator utilization, while paged KV caching reduces fragmentation for variable-length requests. Prefix caching can reuse shared system prompts, but cache keys must include every output-affecting input. Set prompt and generation budgets separately, cancel disconnected streams, and isolate long-context traffic from latency-sensitive requests.

Log model, tokenizer, prompt-template, retrieval, and policy versions. Redact secrets and sensitive user text from traces. A language system is production-ready when its claims are grounded, its costs are bounded, and its failures are visible.
